Pick a RELION .star, cryoSPARC .csg/.cs, or an .mrcs stack. Load reads the particles once and keeps them on the GPU, so every run afterwards starts immediately. Loading another file replaces the current dataset (its results stay saved and come back when you load the same file).

2Classify

Run classifies the loaded particles (or, after Re-run, the selected classes' particles) with every setting on this page as it is now. If a setting that is applied when particles are loaded changed (mask diameter, resolution, GPUs, sampling…), Run loads the particles again first. Stop ends the run after the current iteration and keeps the classes so far; a stopped run can be continued.
